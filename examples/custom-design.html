🎨 Flowise Custom Design Example

📋 Configuration-Based Customization

This example demonstrates how to customize the Flowise chat embed using the theme configuration object. No rebuild required - just modify the JavaScript below!

  • Custom brand colors (purple/pink theme)
  • Custom typography (Poppins font)
  • Adjusted layout and sizing
  • Custom avatars
  • Welcome message and starter prompts
  • Custom button positioning

💬 Your Custom Chatbot

The chat widget will appear in the bottom-right corner. Click the button to open it!

⚠️ Important: Replace YOUR_FLOWISE_CHATFLOW_URL in the script below with your actual Flowise API endpoint.

🎯 Customization Features

🎨 Colors

  • Button: Purple (#7C3AED)
  • Bot bubbles: Light purple
  • User bubbles: Pink gradient
  • Header: Purple (#7C3AED)

✏️ Typography

  • Font: Poppins (Google Fonts)
  • Body text: 16px
  • User input: 15px

📐 Layout

  • Chat height: 700px
  • Chat width: 450px
  • Border radius: 12px
  • Button: Bottom-right (24px)

⚙️ Features

  • Welcome message enabled
  • Starter prompts included
  • Footer with "Powered by..."
  • Feedback buttons
